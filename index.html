Last-Night Top 20

  1. OSPF is link-state, cost-based, Area 0 is the backbone.
  2. EIGRP uses DUAL; the feasible successor is a ready, loop-free backup.
  3. BGP picks by Weight, Local Preference, then shortest AS Path.
  4. STP blocks loops; RSTP converges in seconds, not 30-50.
  5. EtherChannel: use LACP, the open standard, not PAgP.
  6. HSRP is Cisco, VRRP is open, GLBP load-balances.
  7. QoS prioritises voice and video when links are busy.
  8. DHCP Snooping + DAI + Port Security stop rogue servers and ARP spoofing.
  9. A firewall denies by default; policies are checked top to bottom.
  10. Stateful firewalls remember sessions; stateless ones do not.
  11. SNAT hides LAN users behind one public IP; DNAT / VIP publishes a server.
  12. NGFW adds application control, IPS, antivirus and web filtering.
  13. IPS blocks attacks; IDS only reports them.
  14. SSL inspection decrypts HTTPS to inspect it; it needs a CA on devices.
  15. IPsec Phase 1 builds the management tunnel; Phase 2 carries data.
  16. SSL VPN is for travelling users; IPsec VPN is for site-to-site.
  17. FortiGate HA: Active-Passive waits; Active-Active shares the load.
  18. SD-WAN steers each app to the healthiest WAN link automatically.
  19. Troubleshoot in order: link, IP, route, policy, NAT, application.
  20. Always check the log and the policy ID before changing anything.
